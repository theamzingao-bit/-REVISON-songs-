### Step 1: Copy the Code 1. Scroll up to the black code box in my previous message. 2. Select and copy all of the code inside it. --- ### Step 2: Set Up GitHub 1. Open Safari and go to **github.com**. 2. Tap the **+** icon at the top-right corner. 3. Tap **New repository**. 4. Type `revision-songs` in the **Repository name** box. 5. Check the box next to **Add a README file**. 6. Scroll down and tap **Create repository**. --- ### Step 3: Add Your Code File 1. Tap **Add file**, then select **Create new file**. 2. Type `index.html` in the file name box. 3. Paste your copied code into the big text area below. 4. Tap **Commit changes...** at the top right, then tap **Commit changes** again to save. --- ### Step 4: Turn It Into a Webpage 1. Tap **Settings** (the gear icon) near the top of the page. 2. Tap **Pages** from the menu on the left side of your screen. 3. Under **Branch**, tap the dropdown button that says **None** and change it to **main**. 4. Tap **Save**. --- ### Step 5: Save to Your Home Screen 1. Wait 2 minutes for GitHub to set up the site, then refresh the page. 2. Tap the blue web link that appears under the **GitHub Pages** banner at the top. 3. In Safari, tap the **Share icon** (the square with an arrow pointing up, next to the `+` button). 4. Scroll down the menu and tap **Add to Home Screen**. 5. Tap **Add** in the top-right corner.
